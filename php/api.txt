API - Velas S. Tomé

Todos os endpoints retornam JSON e, com exceção da autenticação, exigem uma sessão PHP válida.

Autenticação
- GET    php/auth.php                  -> consulta sessão
- POST   php/auth.php                  -> login ou cadastro (campo action)
- DELETE php/auth.php                  -> logout

Dados
- GET/POST/PUT/DELETE php/clientes.php
- GET/POST/PUT/DELETE php/produtos.php
- GET/POST            php/vendas.php
- GET/POST/PUT/DELETE php/pedidos.php
- GET/POST            php/controle.php
- GET/DELETE          php/dashboard.php
- GET/PUT             php/configuracoes.php

POST php/cadastro_usuario.php - cadastra um novo usuário no banco (usuario, senha, confirmar_senha).
